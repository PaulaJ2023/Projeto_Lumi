# Base de conhecimento da LUMI

Esta pasta documenta os três agentes especialistas:
- [LUMI Acadêmica](academica.md)
- [LUMI Financeira](financeira.md)
- [LUMI Campus](campus.md)

A base efetivamente carregada no chat é `data/base-conhecimento-lumi.json`.

A LUMI é um protótipo acadêmico independente, baseado em informações públicas da UnP. Ela propõe centralizar orientações, mas não é canal oficial e não consulta dados pessoais ou executa operações institucionais.

## Padrão de resposta
- Explicar primeiro; não responder apenas com link.
- Dar passos práticos quando houver informação suficiente.
- Fazer uma pergunta curta quando faltar contexto.
- Mostrar a fonte apenas quando solicitada ou necessária para consultar calendário, edital ou documento vigente.
- Não inventar prazos, valores, requisitos ou políticas.
- Não pedir senhas, dados bancários ou documentos pessoais.
- Não afirmar que uma operação individual foi concluída.

O Forms ainda não possui respostas. A atividade exige pelo menos 30 respostas reais. Acrescentar prioridades e perguntas frequentes dos alunos somente após analisar os dados coletados.
